# Bot character kit

Artwork supplied by the project owner on 2026-10-19: 24 silhouettes and 20 faces
from `kit-bots`, plus 24 independent accessories from `acessorios-bots`.

Every SVG uses the same 128 × 128 coordinate system. Preserve its transparent
margins. Bodies inherit the bot color; the original lighting remains above it.
Faces use warm white. Accessories preserve their own colors and are drawn above
the body and face, in their saved order.

Only bundled SVGs are rendered. Profiles store validated catalog IDs and bounded
placement values, never SVG markup, URLs or file paths. Each rendered layer has
its own gradient IDs so simultaneous avatars cannot recolor one another.
